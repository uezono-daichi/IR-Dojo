# IR Dojo — テスト版をさわってください

**中のファイルは開かないでください。** 答えが書いてあります。

- `scenarios/` — **真相そのもの**（どれが侵害され、どれが偽の手がかりか）
- `irdojo/` — コードのコメントにも真相が出ます

読んでよいのは、この手引きと、ブラウザに出る画面だけだと思ってください。
（うっかり開いてしまっても大丈夫です。その演習だけ飛ばして、別のを遊んでください。）

---

## 1. 動かす

**必要なもの: Python 3.11 以降** だけです。
（`python3 --version` で確認できます。入っていなければ <https://www.python.org/downloads/> から）

### Mac

`起動_Mac.command` をダブルクリック。
「開発元を確認できません」と出たら、**右クリック →「開く」**。

### Windows

`起動_Windows.bat` をダブルクリック。

### うまくいかないとき

ターミナル（Windows はコマンドプロンプト）でこのフォルダに移動して、

```
python3 -m venv .venv
.venv/bin/pip install -e .          # Windows: .venv\Scripts\pip install -e .
.venv/bin/python -m irdojo          # Windows: .venv\Scripts\python -m irdojo
```

ブラウザで <http://127.0.0.1:8000> が開きます。
**あなたの機械の中だけで動きます。** どこにも送信していません。

終わるときは、ターミナルの画面で `Ctrl+C`。

---

## 2. 遊ぶ

**1本 10分くらい**です。5本入っています。どれからでも構いません。

お願いが4つあります。

- **調べてから決めてください。** 分からないまま決めても進みます（それも測っています）
- **途中で人に聞かないでください。** 分からなかった場所そのものが知りたいことです
- **終わったら講評まで読んでください。** そこで初めて答えが出ます
- 余裕があれば、**同じ演習をもう一度、別の「対応方針」で**やってみてください。
  ここがこの道具の中心です

途中でやめても構いません。**やめた場所を覚えておいてください。**

---

## 3. 記録を送ってください

遊ぶと、結果が自動で保存されます。**この中に答え（真相）は入っていません。**
点数・押した手の順番・かかった時間だけです。

| | 場所 |
|---|---|
| Mac | `~/.irdojo/results/` （Finder で ⌘⇧G → `~/.irdojo/results`） |
| Windows | `C:\Users\<あなた>\.irdojo\results\` |

**`results` フォルダごと zip にして送ってください。**

---

## 4. 3つだけ教えてください

感想ではなく、**やったこと**を教えてください。

1. **最後に押した手を、なぜ押しましたか**
2. **方針を変えたとき、何を変えましたか**（2周目をやった方だけ）
3. **意味が分からなかった画面はどこですか**
   — 場所だけで構いません。理由は考えなくて大丈夫です

「面白かった／難しかった」は書かなくて結構です。
**どこで手が止まったかは、記録のほうに出ています。**

## 困ったら

- 画面が真っ白 → ブラウザを再読み込み（Mac: ⌘R / Windows: Ctrl+R）
- 「サーバに接続できません」 → 起動用のファイルをもう一度ダブルクリック
- 動かない → 画面の写真を撮って送ってください。こちらで見ます
